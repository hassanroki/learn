02. => Tailwind CSS with NPM:
------------------------------
2.1 Create package.json file:
-----------------------------
Command: npm init -y


2.2 Install Tailwind CSS:
-------------------------
Command: npm install tailwindcss @tailwindcss/cli


Now, create a folder named src, then create an input.css file.

Edit src/input.css:
-------------------
@import "tailwindcss";


Now, create a folder named dist, then create an output.css file.

Edit dist/output.css:
---------------------

Now, edit package.json:
-----------------------
  "scripts": {
    "build": "tailwindcss -i ./src/input.css -o ./dist/output.css",
  },

Then, Command: npm run build


2.3 Load Tailwind CSS:
----------------------
<link rel="stylesheet" href="dist/output.css" />


বার বার CSS পরিবর্তন করে npm run build command দেওয়া ভালো নয় সে জন্য watch চালু করবো।
edit pakage.json:
-----------------
  "scripts": {
    "build": "tailwindcss -i ./src/input.css -o ./dist/output.css",
    "build:watch": "tailwindcss -i ./src/input.css -o ./dist/output.css --watch",
  },

Then, run the command: npm run build:watch



Tailwind CSS Minify:
-------------------
  "scripts": {
    "build": "tailwindcss -i ./src/input.css -o ./dist/output.css",
    "build:watch": "tailwindcss -i ./src/input.css -o ./dist/output.css --watch --minify",
  },
Then, run the command: npm run build:watch
